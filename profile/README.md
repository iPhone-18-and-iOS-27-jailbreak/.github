## Overview

iPhone 18 iOS 27 Jailbreak Research is a project dedicated to the latest jailbreak research and iOS customization developments for Apple's iPhone 18 generation.

The project tracks security research, exploit demonstrations, jailbreak development, system modification techniques, and tools relevant to modern Apple hardware.

In October 2026, the security research team Calif demonstrated an untethered jailbreak on an iPhone 18 Pro running iOS 27.0.1. The demonstration showed root access surviving a device restart.

However, the research team has not released a public jailbreak installer or a supported end-user installation procedure.

This repository therefore focuses on research documentation, compatibility tracking, security analysis, and legitimate iOS customization tools. It does not claim to provide a working universal jailbreak.

## Firmware Features

### Untethered Jailbreak Research

An untethered jailbreak is designed to remain active after a device restart without requiring the user to repeat the jailbreak activation process.

Calif demonstrated this behavior on an iPhone 18 Pro running iOS 27.0.1.

The demonstration included:

- Root shell access.
- System-level modification.
- Persistence across a reboot.
- Access through SSH.
- Demonstration of modified system behavior.

The researchers have not published a general-purpose end-user installer.

### Exploit Research

No. Dopamine's documented hardware support does not extend to the iPhone 18 generation.

No. palera1n uses checkm8, which applies to older Apple hardware and not iPhone 18.

### 9. Can I customize iPhone 18 without jailbreak?

Yes. Supported options include Shortcuts, widgets, wallpapers, icons, Focus modes, and IPA sideloading.

### 10. Can a future iOS update block jailbreak research?

Yes. Apple security updates can patch vulnerabilities used by researchers.

### 11. Is a jailbreak demonstration the same as a public release?

No. A demonstration proves that researchers achieved a result under specific conditions. A public release requires a usable and documented tool.

### 12. How can I verify a future jailbreak release?

Check the original developer repository, release notes, supported device list, firmware compatibility, and installation documentation.
